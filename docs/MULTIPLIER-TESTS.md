## E2 虚弱×易伤×强效的位置关系 —— 推荐第一个做

**问题**：虚弱（攻方-25%）、易伤（受方+50%）、强效（面板）三个区是互乘还是合并？
**配置**：希洛主输出 + 朵尔（工具人）+ **带「冬夜追忆」轮**的任意人。全部卸光其他输出向命轮，记好面板。
**操作**（一场战斗内，同一张6级恨意宣泄，每次取非暴击值）：
1. 开战（冬夜追忆易伤自动挂前排，持续2回合）→ 打 → **D_A**
2. 朵尔放「外域手术」（全体虚弱1层1回合）→ 希洛再打 → **D_B**
3. 磨到易伤/虚弱都过期 → 打 → **D_C**（基准）

| 对照 | 假设A：虚弱/易伤/强效各自独立乘算 | 假设B：敌我状态同区加算 |
|---|---|---|
| D_A / D_C | **1.50** | 1.50 |
| D_B / D_C | **1.125**（=1.5×0.75） | **1.25**（=1+0.5-0.25） |

判读就看 D_B：1.125 → 三区独立（引擎现状）；1.25 → 状态合并一个加算区。

## E6 触腕伤害公式 —— ✅ 定案（2026-10-01 v5 终版结构，用户给出+全量验证；v1-v4 为历史见下）

**最终公式（v5，初始触腕·单次，回合末自动攻击，潮涌，向上取整✓）**：

```
触腕单次 = ceil( 0.095 × Σ各队员[ ceil(攻击 × (1 + 0.03×灵塑适性)) ] × (1 + 面板强效/100) × 独立词条乘区 ) + 固定触伤点数
```
（0.095 = 0.95×0.1；用户口述结构"各唤醒体攻击×(1+灵塑适性提高量)向上取整后的和×0.95"）
- **全对称、无 Base_队/X/0.116/×1.5**：四名队员等权进求和；v1-v4 的 Base_队、+0.116×X攻击力、×1.5 面板强效全部作废——×1.5 是旧结构缺"灵塑适性攻击通胀"的补偿伪影；**强效实为线性 ×(1+面板强效/100)**（与于暴雨之中×1.288 轮测自洽，"面板/装备两区"假说撤销）
- **灵塑适性通用部分（+3%/级）以攻击通胀进公式**（队员项 ceil(攻×(1+0.03灵塑))，adapt10=×1.3，与艾瑞卡力量×1.3 同源）；但**面板强效不来自灵塑**（来自深化组，见下）
- **验证精度：56/56 全部 ±1 内（100%）**（系数 0.095~0.096 区间均成立）；第四队 图鲁+戈利亚+索雷尔+血链（面板强效14.4）= **100 精确命中**；法洛思条款 ×1.2（A队）/×1.0（B队）后 A88/B50 全中

- **✅ 取整位置定案（2026-10-01 实测）**：图鲁+戈利亚+弥利亚姆+索蕾尔 读数 **83 = A（逐成员向上取整后求和：ceil(864×0.095)=83）**，B（精确和 862.8→82）排除——**公式全闭合**：`单次 = ceil( 0.095 × Σ各队员ceil(攻击×(1+0.03灵塑)) × (1+Σ面板强效/100) × 独立词条 ) + 固定触伤点数`。备用队②③无需再测。
